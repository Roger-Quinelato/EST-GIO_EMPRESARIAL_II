# Logo — BabelStack Júnior

Conceito: junção de **linguagem/comunicação** com **camadas de software (stack)**.
Estilo moderno, minimalista, flat e vetorial. Paleta da [identidade visual](../../docs/identidade_visual.md):
Índigo `#4338CA`, Teal `#0EA5A4`, Âmbar `#F59E0B`, Grafite `#1E293B`, Branco-gelo `#F8FAFC`.

## Arquivos

| Arquivo | Conceito | Uso |
|---|---|---|
| `mark-camadas.svg` | **A — Camadas (stack)** ⭐ recomendado | Símbolo principal: 3 blocos empilhados (livros + software). |
| `mark-balao-codigo.svg` | B — Balão de fala + `</>` | Alternativa: linguagem (fala) + código. |
| `mark-monograma.svg` | C — Monograma "B" | Alternativa em tile app-icon (fundo índigo). |

| `favicon.svg` | Símbolo A em tile claro | Aba do navegador / ícone do app. |

## Como usar

- **Favicon no site:** `<link rel="icon" type="image/svg+xml" href="assets/logo/favicon.svg">`
- **Cabeçalho:** usar `lockup.svg`; em telas estreitas, trocar pelo símbolo (`mark-camadas.svg`).
- **Monocromático:** trocar todos os preenchimentos por `#1E293B` (claro) ou `#FFFFFF` (sobre fundo escuro).
- **PNG / favicon .ico:** abrir o SVG no navegador ou no Figma e exportar nas resoluções 512/192/32/16.

## Observações

- Os arquivos `mark-monograma`, `lockup` (que usam texto) carregam a fonte **Space Grotesk** via Google Fonts.
  Para versão final/impressão, **converter o texto em contornos no Figma** (evita depender da fonte instalada).
- Versão vetorial editável no Figma: ver `docs/identidade_visual.md` (arquivo `BwHP5UWR51JXmtGOW9cfS1`).

> Falta **escolher o conceito definitivo** (A, B ou C) para fixar como logo oficial nos slides, no site e na capa do documento.
