# PRD — BabelUX

**Produto:** BabelUX — Consultoria de redesign UX/UI
**Categoria:** Serviço de design (consultoria) · **Valor (privado):** R$ 500–1.500 [estimativa] · gratuito p/ escolas públicas
**Autores:** Roger (CTO), Raquel (CPO) · **Status:** rascunho v1 · **Fase de build:** Semana 5

## Problema

Portais e sistemas educacionais existentes têm interfaces confusas e defasadas que elevam a carga cognitiva de alunos e professores, gerando frustração e abandono de funcionalidades. Escolas e professores percebem o problema, mas não têm repertório de UX para resolvê-lo. O custo de não resolver é baixa adoção das ferramentas digitais e experiência ruim de estudo.

> **Natureza do produto:** BabelUX é um **serviço de consultoria**, não um software. O entregável é um pacote de redesign **"Antes/Depois"** em alta fidelidade no **Figma**, com justificativas de usabilidade. Este PRD especifica o *serviço* e seus entregáveis.

## Objetivos

1. Definir um **processo de redesign** repetível (diagnóstico → redesign → entrega) que a dupla consiga executar.
2. Produzir **pelo menos 1 estudo de caso "Antes/Depois"** em alta fidelidade no Figma para o portfólio.
3. Tornar tangível o valor de UX para o público educacional (heurísticas aplicadas).
4. Reaproveitar o **design system / tokens** já criados na identidade BabelStack.

## Não-objetivos

- **Não** entregará implementação em código do redesign (só protótipo Figma) no escopo base.
- **Não** fará pesquisa de usuário em larga escala (entrevistas/testes com N grande) — análise heurística + amostra mínima.
- **Não** cobrirá redesign de produto físico/serviço offline.
- **Não** incluirá manutenção contínua/retainer no v1.

## Personas e user stories

**Escola/professor com sistema defasado (cliente):**
- Como cliente, quero ver um "antes/depois" da minha interface, para entender o ganho de usabilidade.
- Como cliente, quero recomendações priorizadas, para saber por onde começar mesmo com pouco orçamento.

**Aluno(a) (usuário final do sistema redesenhado):**
- Como aluno, quero telas mais claras e navegação intuitiva, para concluir tarefas sem me perder.

## Requisitos (entregáveis do serviço)

### Must-Have (P0)
- **Diagnóstico heurístico** da interface-alvo (lista de problemas com severidade, baseada nas heurísticas de Nielsen).
  - *Aceite:* documento com ≥5 problemas identificados, cada um com severidade e princípio violado.
- **Protótipo "Depois"** em Figma (alta fidelidade) de ≥2 telas-chave, usando os tokens BabelStack.
- **Comparativo Antes/Depois** exportável (imagens) para o portfólio (Seção 8).

### Nice-to-Have (P1)
- Mini guia de recomendações priorizadas (quick wins vs estruturais).
- Protótipo navegável (links entre telas no Figma).

### Future Considerations (P2)
- Teste de usabilidade com usuários reais.
- Handoff para implementação em código.
- Componentização do redesign num design system entregável.

## Métricas de sucesso

- **Líderes:** ≥1 estudo de caso "Antes/Depois" concluído e exportado; ≥2 telas redesenhadas.
- **Defasados:** uso do estudo de caso para captar ≥1 cliente/parceria [estimativa]; feedback positivo de usabilidade.
- **Acadêmico:** comparativo presente no documento e na apresentação.
