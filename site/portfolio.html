Portfólio

Cinco soluções demonstráveis

Cada produto resolve uma dor concreta da sala de aula, com stack open-source e custo zero.

Business Intelligence

LingoBoard

Dashboard que transforma planilhas de turmas em indicadores visuais de notas, frequência e risco de evasão. Upload de CSV, gráficos e ranking de alunos em atenção.

Python · Streamlit · Pandas

Aplicação web

VocabDeck

Flashcards com repetição espaçada (sistema de Leitner). O aluno cria baralhos, estuda e o app reagenda os cards conforme os acertos; o progresso fica salvo no navegador.

HTML · CSS · JavaScript · localStorage

Template

EduLanding

Modelo de landing page educacional, responsivo e fácil de personalizar, para divulgar cursos, eventos e feiras — com exemplo pronto da "Feira Cultural de Idiomas".

HTML · CSS · JavaScript

Consultoria UX/UI

BabelUX

Serviço de redesign de interfaces: diagnóstico heurístico dos problemas de usabilidade e protótipo navegável "Antes/Depois" com a identidade da marca.

Figma · Design tokens

Automação

IntegraSchool

Automação de rotinas administrativas: lê os dados da escola, gera resumos e lembretes e organiza arquivos — em modo simulação, com registro de execução (log).

Python · CSV
